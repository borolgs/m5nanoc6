# M5NanoC6

Firmware for the [M5Stack NanoC6 Dev Kit](https://docs.m5stack.com/en/core/M5NanoC6) (ESP32-C6), written in Rust on `esp-hal` + `embassy`.

# Quickstart

```bash
cargo check
cargo run
```

`cargo run` flashes the connected board via `espflash` and opens the serial monitor.
